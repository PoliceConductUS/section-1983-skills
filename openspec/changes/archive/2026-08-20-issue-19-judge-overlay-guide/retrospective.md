# Retrospective

## What worked

- Reusing the canonical corpus and transfer-card contracts kept the method
  aligned with the validator instead of creating parallel prose rules.
- Treating court conduct as sourced compliance input prevented anti-gaming from
  collapsing into a warning label with no operational boundary.
- A schema-valid fictional card paired with an incomplete-corpus result made the
  evidence-strength and degradation rules concrete.

## What changed during implementation

The initial RED suite used simple Markdown and keyword checks. Adversarial
review expanded the seam to all operative link forms, parsed nonblank conduct
records, shared validator rules, affirmative no-change duties, exact fictional
example keys, and a raw exact structural-only Scholer paragraph.

The first guide published a command valid only from an unstated installed-skill
directory and used an angle-bracket shell placeholder. Whole-story review caught
that defect. The final test executes the exact repository-root command against a
canonical fictional fixture.

## Future rule

An overlay transfers only validator-passing neutral evidence at its supported
strength. Court-specific conduct comes from current official sources and remains
a compliance constraint, never an optimization target. Structural examples do
not carry substantive conclusions. Every published command must be executed from
the context the documentation claims.

# Staged-development guided results

Five fresh-context agents applied the revised planning, drafting, and validation
contracts to the same synthetic staged-development problem used for the
baseline. The successful set was runs 1, 2, 3, 5, and replacement run 4b.

All five successful runs:

- kept the possible failure-to-train path `preserve-internal` and refused an
  omnibus or speculative preservation allegation;
- separated current source facts, supported inferences, and unavailable
  municipal material expected in discovery;
- identified the missing path connections, expected records or testimony, and
  controller without predicting contents;
- required each proposed request to identify independent relevance to a named
  live claim or defense and to record the pending qualified-immunity stay issue;
- preserved `requested_at`, `produced_at`, and `first_reasonably_knowable_at`,
  using explicit unknown or not-yet values;
- required a dated diligence record, exact amendment deadline and source,
  evidence threshold, reassessment triggers, and limitations or relation-back
  risk;
- required Rule 16 good cause, including diligence and the explanation for
  delay, before Rule 15 after the scheduling-order deadline;
- left amendment subject to actual developed support and litigation-principal
  approval; and
- treated predictions about unavailable municipal records as expected discovery
  that validation cannot pass as existing fact or evidence.

## Corrective pressure-test cycle

The original fourth guided run calculated a calendar deadline from the phrase
“21 days away” and the session date even though the scheduling order and a
source-backed as-of date were absent. A focused RED test captured that failure.
The contract now says a relative interval is not an exact date and prohibits the
calculation without both sources. Fresh replacement run 4b recorded the exact
date as `unknown`, preserved the relative statement, and required the scheduling
order and source-backed as-of date.

These behavior runs test instruction-following under pressure. They do not
decide whether an actual allegation is plausible, whether discovery is
authorized, or whether amendment should be granted.

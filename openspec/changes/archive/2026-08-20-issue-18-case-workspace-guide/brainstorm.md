# Case Workspace Guide Brainstorm

## Approved direction

Add one concise root-level guide and link it from the README. Explain the first
hour of establishing the artifact roles assumed by the skills without creating a
template, repository, skill, or scaffolding script.

## Boundaries

- Use generic synthetic examples only.
- Describe roles and one example layout, not mandatory filenames.
- Keep missing evidence and unavailable validation explicit.
- Use the immutable tagged installation already established by Issue 16.
- Add no root `docs` or `.superpowers` directory.

## Rejected alternatives

- A template would prematurely freeze a private project layout.
- A scaffolder would automate a contract that has not yet been tested through
  stranger adoption.
- Embedding the full guide in README would bury skill discovery and release
  installation under unrelated detail.

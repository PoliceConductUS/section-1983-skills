# Staged-development baseline

Five fresh-context agents applied the proposition-classification version of the
Monell skills to a common synthetic problem: strong individual claims,
incomplete municipal records, a pending qualified-immunity motion and requested
discovery stay, an amendment deadline 21 days away, and pressure to plead every
Monell theory merely to preserve it.

## Shared behavior

All five runs correctly refused to turn unavailable policy, training,
discipline, or complaint-history materials into present facts. All five kept the
incomplete paths internal and recommended targeted evidence development rather
than a speculative omnibus count. This confirms that the proposition-placement
rule was working before the staged-development extension.

## Run-by-run omissions

1. The first run identified path-specific evidence targets and the amendment
   deadline but did not require a separate relevance statement for each request,
   exact request/production/first-reasonably-knowable dates, or a Rule 16-good-
   cause gate after the deadline.
2. The second run distinguished individual-claim and Monell discovery and
   recommended deadline protection but omitted a complete restrictions/stay
   record, limitations or relation-back risk, and an exact evidence threshold
   for each preserved path.
3. The third run proposed an “amendment ledger” and narrowly necessary
   discovery, but did not capture request-specific relevance, production and
   knowability dates, limitations or relation-back risk, or Rule 16 before
   Rule 15. Its amendment trigger was only “nonconclusory, source-bounded
   facts,” not a path-specific recorded threshold.
4. The fourth run required focused discovery and replanning on new material, but
   did not record exact request/production/knowability dates, limitations or
   relation-back risk, or the after-deadline Rule 16 gate. Its statement that
   discovery should be “needed for the individual claims” did not tie each
   request to a named live claim or defense.
5. The fifth run offered a useful proposed-amendment matrix and called for a
   “concrete proposed discovery-and-amendment schedule,” but omitted the same
   date triad, an explicit limitations or relation-back assessment, and the Rule
   16-first standard. Its request categories had general path relevance rather
   than a distinct relevance theory for each request.

## RED conclusion

The old contract reliably controlled proposition placement but left the staged
strategy to agent discretion. The extension therefore needs a required,
field-complete internal record and conditional discovery/amendment gates. It
must not replace legal judgment with deterministic sufficiency checking.

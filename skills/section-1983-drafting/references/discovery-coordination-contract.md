# Discovery Coordination Contract

Use this reference to coordinate the five public Section 1983 discovery skills.
It does not draft or audit an artifact. Each peer skill owns its named work and
repeats the operative minimum so that independent installation remains safe.

## Discovery Target Map

Every request-specific target uses a stable `target_id`. One map row represents
one legal tuple: `claim`, `defendant`, and `element`. Each row also records
`factual_gap`, `likely_custodian`, `expected_native_source`, and approved source
IDs. Every value must be meaningful and nonblank. A null, empty, placeholder,
collective, or facially unbounded value is a reported gap, not a completed map.

The `factual_gap` separates what approved sources presently support from what
remains missing. A `likely_custodian` remains an expectation and is not
established. An `expected_native_source` remains an expectation and is not
established. A request serving more than one legal tuple uses more than one map
row and preserves every applicable stable target ID.

## Proportionality

Bounded proportionality states:

- a bounded time or date scope;
- a bounded actor or entity scope;
- a bounded system or category scope;
- the target's importance;
- supplied burden information and its limits; and
- supported narrower alternatives.

Use approved source IDs for each supplied premise. Do not invent burden,
importance, a custodian, a source, or a narrower alternative. Missing
information remains explicit.

## Existence before content

Determine whether an expected source exists before treating its content as
established. If existence or content is unverified, ask about existence and
identification, request production if the source exists, or use a conditional
premise. An expected source does not prove what it depicts, records, or says.

## Localization and sources

Use only sources supplied in the declared input roles or retrieved under the
skill's internet policy. Verify court-specific numerical limits, timing,
conference duties, privilege-log requirements, and other local rules through
approved localization sources. `audit-authorities` owns authority verification.
A missing approved rule or order is a scoped gap, not permission to supply a
generic rule.

## Stable downstream links

Written discovery creates target and request IDs. Response audits preserve the
served request and target IDs. Meet-and-confer correspondence consumes the
completed audit without remapping it. Privilege-log work preserves request or
target relationships. Deposition topics preserve target and approved source IDs.
No downstream skill silently changes an upstream request, map, audit, or
position.

## Plaintiff decisions

Routine source-supported wording may proceed. A material strategy choice uses
`PLAINTIFF DECISION REQUIRED`, states the available choices and consequences,
preserves the current artifact, and selects no strategy. This includes service,
sequence, priority, cap allocation, narrowing, stipulation, conferral, date
selection, waiver theory, fees, sanctions, motion practice, deposition selection
or order, 30(b)(6) scope, impeachment timing, and theory-changing follow-up.

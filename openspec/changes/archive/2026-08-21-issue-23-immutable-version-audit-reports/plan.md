# Implementation Plan: Immutable Version-Local Quality-Control Reports

## Goal

Make every independent quality-control result a new immutable report inside the
audited version folder while preserving advisory remediation and the existing
non-mutation boundary.

## Architecture

Extend the repository governance owner, repeat a compact install-local contract
in behaviorally affected public skills, and extend the existing governance
validator. Use temporary repositories for deterministic contract failures and
fresh synthetic version folders for actual filesystem pressure behavior.

## Constraints

- Use RED-GREEN TDD and fresh-agent skill pressure tests.
- Keep the current behavioral quality-control classifier.
- Add no report-writing engine, dependency, workflow, root `docs/`, or
  `.superpowers/` directory.
- Commit and run `git town sync` after every commit.
- Archive this change on the Issue 23 branch.

## Verification

- Focused report-contract and governance tests.
- Fresh authority, discovery-response, and hybrid audit scenarios.
- Full `npm run validate`, strict OpenSpec validation, formatting, diff, branch,
  forbidden-folder, and origin-head checks.

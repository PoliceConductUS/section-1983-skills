# Issue #61 Declared-Folder Static-Role Launcher Plan

## Goal

Launch one protected static litigation role against selected ordinary files from
declared read-only input folders in a fresh isolated process and return only
bounded advisory output.

## Constraints

- One full absolute output folder is mandatory.
- All transient work is under `<output-folder>/temp/`.
- No executable, adapter, role, path, or policy comes from task or input data.
- No child receives absolute paths, ambient environment, credentials, session,
  prior conversation, or direct publication authority.
- No package, graph, CaseGraph, Git, role sweep, or persistent agent process.
- Every behavior change follows RED, minimal GREEN, and immediate push.

## Tasks

1. Specify and implement static role, task, logical-selection, and exact-byte
   snapshot binding.
2. Specify and implement adapter attestation, run-scoped output-temp workspace,
   bounded request/response, and stable failures.
3. Specify and implement role-specific advisory output plus post-dispatch input
   immutability verification.
4. Route adversarial review through the shared boundary without weakening its
   domain contract.
5. Run focused and full validation, archive OpenSpec, push, and verify
   exact-head GitHub checks before marking ready.

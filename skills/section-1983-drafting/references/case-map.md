# Case map: what happened, what to file, by when

The first question is never "how do I write this" but "which document does this
event call for, and what is the clock." Federal baselines below; local rules can
shorten, lengthen, or add requirements, so run the localization protocol
(`localization.md`) before relying on any deadline.

| Event                                                        | Responsive document                             | Federal baseline deadline                                                                         | Reference                     |
| ------------------------------------------------------------ | ----------------------------------------------- | ------------------------------------------------------------------------------------------------- | ----------------------------- |
| Ready to sue                                                 | Complaint                                       | Statute of limitations (state personal-injury period; accrual is federal)                         | documents/complaint.md        |
| Defendant files a motion to dismiss                          | Response to the motion                          | Set by local rule (often 14–21 days); check it                                                    | documents/mtd-response.md     |
| Need to fix or expand the complaint                          | Amended complaint, or motion for leave to amend | As of right within 21 days of the answer or 12(b) motion, Rule 15(a)(1); otherwise leave required | documents/leave-to-amend.md   |
| Any deadline is too close                                    | Motion for extension of time                    | Before the deadline runs, Rule 6(b)(1)(A); after, excusable neglect required                      | documents/extension-motion.md |
| Magistrate judge issues an R&R against you                   | Objections                                      | 14 days from service, § 636(b)(1), Rule 72; +3 for mail service, Rule 6(d)                        | documents/rr-objection.md     |
| Magistrate judge issues an R&R for you and defendant objects | Response to objections                          | 14 days from service of the objections, Rule 72(b)(2)                                             | documents/rr-response.md      |
| Defendant moves for summary judgment                         | Response, fact statement, evidence              | Set by local rule; check it                                                                       | documents/msj-response.md     |
| Address changes                                              | Notice of change of address                     | Immediately; mail to a stale address still counts as service                                      | none needed; one paragraph    |

Two standing rules:

- Silence is the enemy. An unanswered motion is often granted as unopposed, and
  an unobjected R&R is adopted. When in doubt, file the responsive document or
  an extension motion.
- Calendar the deadline the day the triggering paper arrives, before reading it.

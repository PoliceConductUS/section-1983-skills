# AGENTS.md

## Workflow

Route behavior changes through OpenSpec before implementation. Use Superpowers
execution discipline for planning, implementation, testing, review, and
verification.

## Boundaries

The user retains litigation judgment, including decisions about legal strategy,
positions, concessions, and filing. Keep these public skills as thin wrappers:
general-purpose executable tooling belongs in its owning repository.

## Validation

Run `npm run validate` before completing a change.

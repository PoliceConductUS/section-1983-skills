## Why

The public skills correctly fail closed when strategy, chronology, source,
authority, decision, or gap roles are missing. A new user needs a concise first-
hour guide for establishing those roles without copying a private workspace.

## What Changes

- Add an install-local root guide for starting a case workspace.
- Link the guide from README project-input guidance.
- Test discovery, pinned installation, the required first-hour flow, role
  portability, explicit gaps, and the no-private-material boundary.

## Capabilities

### New Capabilities

- `case-workspace-start-guide`: Document the minimum portable artifact roles a
  new user can establish before using the public skills.

### Modified Capabilities

None.

## Impact

The change adds one root Markdown guide, one README link, and one standard-
library test. It adds no template, script, skill, dependency, or workflow.

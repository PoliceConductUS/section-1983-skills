# Retrospective

The canonical guide originally documented an explicit output root without
identifying one exclusive transient workspace. Restacking on the corrected Issue
#65 implementation made the gap executable: the guide test could inspect the
same process configuration and staging boundary users are told to expect.

Keeping the correction in the shared first-hour guide prevents every later skill
from copying or subtly changing the rule. Later skills need only declare their
logical input roles and durable output artifacts.

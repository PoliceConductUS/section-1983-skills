# Brainstorm

## Outcome

Document a reusable, evidence-bounded method for authoring judge overlays. Use
the existing Scholer overlay only to show the method's structure. Do not export
its judge-specific conclusions as a template.

## Selected shape

Add one root `JUDGE_OVERLAYS.md` guide, route to it from README, and add one
standard-library contract test. The guide points to the existing Rule 59 corpus
schema and validator instead of introducing another data format or tool.

## Method boundary

An overlay may transfer only validated neutral cards. It adds a documented
example, documented cluster, or tendency when the corpus supports that strength.
Otherwise it adds no judge-specific proposition. It never predicts an outcome,
describes judicial psychology, chooses strategy, or turns court conduct into a
persuasion tactic.

## Court-conduct boundary

The author maintains a source-bounded checklist for applicable official rules,
individual procedures, standing orders, candor, civility, ex parte limits,
filing limits, and other express prohibitions or discouragement. Every warning
has an official source identity and checked date. An unverified item is a gap,
not a court requirement.

## Alternatives rejected

- A new judge-overlay skill would add a public capability when the requested
  deliverable is a method guide.
- A copied overlay template would encourage renaming another judge's conclusions
  and bypass the corpus contract.
- Live court research would exceed this documentation story and make the guide
  dependent on current facts not reviewed here.

# Retrospective

## What changed

The shared drafting workflow now audits whether an arrest occurred before
producing ordered defendant presentations. The canonical complaint contract and
completion audit apply the same order to complaint structures, and the
false-arrest actor matrix records arresting-officer status and caller-declared
primary status.

## What stayed separate

The rule changes presentation order only. It does not change factual chronology,
claim-specific allegations, event stages, merits analysis, or the user's
reserved litigation decisions. Case-specific names remain in caller inputs or
test fixtures, not reusable instructions.

## Evidence retained

The branch retains an OpenSpec-first commit, a RED evaluation commit, a separate
GREEN implementation commit, a mutation check, focused and full validation, and
the correction that keeps the bespoke scenario corpus outside the canonical
fixture-loader namespace.

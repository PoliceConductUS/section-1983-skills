their declared recursive read-only input folders. Validate the counsel domain
schemas before semantic work. Resolve every source reference as a
folder-relative path within its declared role and require its recorded SHA-256,
identity, checked date, classification, and validation state to match.

directly beneath the explicit output folder. Use `<output-folder>/temp/` for all
temporary work. No folder-level envelope or generic folder identity is used.

output authority.

# Brainstorm: Judicial Reasoning Profiles without packages

## Accepted direction

Keep the generic builder, evidence classes, anti-prediction rules, neutral
transfer gate, fictional fixtures, and removal of the embedded real-judge skill.
Replace only the rejected persistence abstraction.

Acquisition writes ordinary public-source bytes with domain YAML provenance
directly beneath one explicit output folder. A later compilation invocation
declares that folder as recursive read-only input and writes the profile JSON,
its YAML source index, and validation receipt directly beneath a different
explicit output folder. There is no folder-level envelope, identity, kind,
loader, publisher, registry, graph, or CaseGraph object.
